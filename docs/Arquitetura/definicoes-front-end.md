## Decisões já tomadas

| Item | Decisão | Justificativa |
|------|---------|----------------|
| **Protótipo** | Figma | Ferramenta padrão de mercado para design de interfaces |
| **Colaboração** | Design → Desenvolvedor via Figma Dev Mode | Facilita extração de especificações e ativos |
| **Comunicação com backend** | API REST (formato JSON) | Padrão da indústria, bem documentado |
