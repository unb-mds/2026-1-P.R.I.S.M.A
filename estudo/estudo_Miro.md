# Miro: O Workspace de Inovação Colaborativa

**Miro** é uma plataforma colaborativa online projetada para apoiar o planejamento e a execução de tarefas por equipes em diferentes locais e fusos horários.

## O que é o Miro?

Fundado em 2011 sob o nome *RealtimeBoard*, o Miro evoluiu de uma simples ferramenta de quadro branco visual para um espaço de trabalho de inovação completo. Atualmente, a plataforma é utilizada por mais de 90 milhões de usuários e mais de 250.000 organizações em todo o mundo para realizar brainstorming, planejamento ágil, design de produtos e mapeamento de jornada do cliente.

## Principais Funcionalidades

O Miro se destaca por oferecer um ambiente dinâmico e interativo para as equipes:

*   **Canvas Infinito:** Oferece um espaço inesgotável para a equipe mapear projetos complexos e realizar brainstormings visuais sem restrições de espaço.
*   **Colaboração em Tempo Real:** Permite que os membros da equipe trabalhem simultaneamente no mesmo quadro, visualizando as alterações uns dos outros instantaneamente.
*   **Notas Autoadesivas (Sticky Notes) e Ferramentas de Desenho:** Facilita o registro rápido de ideias e a criação de rascunhos com desenhos livres diretamente no quadro.
*   **Mapas Mentais:** Ferramentas dedicadas para explorar conexões entre ideias de forma visual e simples.
*   **Videoconferência Integrada:** Suporte para integração de chamadas de vídeo diretamente no quadro, mantendo a equipe conectada durante a colaboração.

## Integração com o GitHub Issues

O Miro possui uma poderosa integração de sincronização bidirecional (*2-way data sync*) com o **GitHub Issues** que melhora drasticamente a eficiência de equipes de engenharia e design. Veja como realizar o processo de integração e uso:

**1. Instalação do Aplicativo:**
Acesse o Marketplace de aplicativos do Miro, pesquise por "GitHub" e instale o aplicativo oficial **"GitHub for Miro"**.

**2. Importação de Issues existentes:**
Com o app instalado e sua conta do GitHub conectada, abra a ferramenta no painel lateral do Miro e clique na aba "Import". Selecione o repositório do GitHub com o qual você deseja trabalhar. O aplicativo listará as *issues* abertas; escolha as desejadas e confirme a importação. Elas aparecerão no seu quadro no formato de *app cards* (cartões de aplicativo), exibindo a logo do GitHub no canto inferior direito para identificação rápida.

**3. Edição e Sincronização Bidirecional em Tempo Real:**
Ao expandir o *app card* da *issue* no Miro, você pode editar o título, alterar os responsáveis (*assignees*) e adicionar ou remover etiquetas (*labels*). Ao clicar em atualizar, as modificações refletirão em questão de segundos no repositório do GitHub. Da mesma forma, se alguém fizer atualizações na *issue* diretamente no GitHub, as mudanças aparecerão automaticamente no cartão dentro do Miro.

**4. Criação de Novas Issues a partir de Sticky Notes:**
Se a equipe fez uma sessão de ideação no Miro, não é preciso recriar o texto manualmente no GitHub. Basta selecionar múltiplas notas adesivas de uma só vez, escolher o repositório do GitHub onde deseja criá-las e preencher os detalhes (como atribuições e etiquetas). Imediatamente as novas *issues* serão abertas no GitHub e as notas adesivas originais se transformarão em *app cards* sincronizados no Miro.

**5. Importação Rápida via Link:**
Você pode copiar a URL de uma *issue* existente no GitHub e colar diretamente no quadro do Miro. O aplicativo fará a leitura do link em poucos segundos e criará o *app card* pronto para edição.

## Plataforma para Desenvolvedores (Miro Developer Platform)

Para pessoas que desejam estender as capacidades da plataforma, o Miro oferece um ecossistema completo:

*   **Miro Web SDK:** Biblioteca JavaScript para construir aplicativos que ajudam a criar e gerenciar conteúdos de forma interativa dentro da interface do Miro.
*   **REST API:** Conecta os quadros do Miro a produtos e sistemas de terceiros.
*   **Live Embed:** Permite a incorporação de um quadro do Miro em aplicações web ou sites por meio de um iFrame.
*   **Integração com IAs via MCP:** O servidor *Model Context Protocol* (MCP) do Miro permite que você conecte o quadro a ferramentas de IA para desenvolvimento (como Cursor, Claude Code, GitHub Copilot e Replit). Com isso, a IA consegue gerar código se baseando diretamente nos seus diagramas de arquitetura visual e regras de negócios.

## Preços e Planos do Miro

O Miro oferece diversas opções de planos para se adequar a diferentes necessidades:

*   **Free (Gratuito):** Funcionalidades básicas ideais para usuários individuais ou equipes pequenas.
*   **Team:** Ferramentas de colaboração aprimoradas para times de pequeno e médio porte.
*   **Business:** Funcionalidades mais avançadas focadas em equipes maiores e processos complexos.
*   **Enterprise:** Soluções personalizadas com segurança extra, governança avançada e suporte dedicado.
